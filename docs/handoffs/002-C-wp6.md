### 守卫数学（全部精确，不许放宽）
- 32-bit 检查（pow/shl 的 k）：len(k)>10 拒；<10 收；==10 逐位高位→低位与烘焙常量
  4294967295 字典序比较（E=已经分出大小标志）。
- limbs 上下界（十进制位数 D 的函数，log2(10)<3.322、>(D−1) 下界用 3.3219>log2(10)−ε）：
  `U(D)=1+Σ_{j≥1}[D·3322 ≥ j·64000]`（bl < D·3.322 ⟹ limbs=1+⌊(bl−1)/64⌋ ≤ U）；
  `L(D)=1+Σ_{j≥1}[(D−1)·3321 ≥ j·64000]`（v≥10^{D−1} ⟹ bl ≥ ⌊(D−1)·log2(10)⌋+1 ⟹ limbs ≥ L）。
  以 `_geq_expr(3322*n1, 64000*j)` 阈值计数 Expression 实现 = **一步**出 U/L（编译期行数
  ~425+213×共享一组，多臂复用同一相位行）。离线穷举验证 U/L 界对 D≤8191 全部成立。
- pow：拒 ⟺ limbs(base)·k·8 > MAX：若 8·U·k ≤ MAX 收；8·L·k > MAX 拒；**中段带**（罕见）
  跑 ÷2 折半 bitlen 循环出精确 limbs 再判（确定、慢，容量文档化）。
- shiftLeft：拒 ⟺ (v≠0) ∧ (size(v)+⌊k/8⌋+1 > MAX)：⌊k/8⌋= 丢 k·125 末 3 位十进制；size 用
  8·U/8·L 同上，中段带 bitlen 循环。`shiftLeft 0 k` 永收（!v.is_zero() 分支，实测 B:env_shl1_0）。
- succ/add/sub/mul：结果 r 链头 n 出来后查 `8·size_bounds(n) > MAX`（同 U/L/带结构）。
- infer_lit：字面量 n 位数同上检查（K_LIT nat 推断臂进入共享守卫相位）。

### 循环相位设计（新 X 号，沿用 div 4/5/6、pow 10/13 的多相位风格）
- ÷2 高位→低位 pass：每 digit q=5·c+d/2，c′=d%2，E=2·nzflag+c′；shiftRight/land/lor/xor/gcd 共用。
- ×2 低位→高位 pass：d′=2d+c，c=(2d+c≥10)（addfam 同形单操作数）。shiftLeft 轮、land 的 pow2。
- shiftRight：轮=÷2pass+dec(s)pass（phase13 同形）；终止 ⟺ s 下溢 或 a 的 nzflag=0。
  巨大 s 不迭代（a==0 早停）。无尺寸检查（K:730，实测 shr_bigshift OK）。
- land/lor/xor：轮数=max(bitlen)：parity=digit0%2（O(1)），bit=and/or/xor(la,lb)（线性式），
  r+=bit·pow2（加法 pass，乘 bit 门控），pow2×=2，a÷2，b÷2，双 nzflag 或门。
  输出链长 max(n1,n2)+1 起（前导零由既有 decode 兼容）。
- gcd：二进制 gcd（GMP 等价，减法欧氏会爆）：偶→÷2（复用 pass），奇奇→大减小（borrow pass
  复用），终止 b==0（现有 nzflag），结果 ≤ min(a,b)。
- 容量口径：kernel 接受的 pow/shiftLeft 结果（≤128MB=3e8 十进制位）超出机器 8191 位链上限
  ——与既有 mul 同源的容量限制，守卫只保证**判定**精确，物化超限时与非守卫算子一样表现为
  步数耗尽；差分语料全部取在可物化区。文档进 VM_SPEC。
