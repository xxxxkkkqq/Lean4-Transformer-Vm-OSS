# 010. 守卫阈值 _T_DIG_CMP 的 fp32 取整方向：向上

- 状态：accepted（2026-09-15，WP6，代理 C3）
- 关系：`lean_vm/build_vm.py:2189-2207`；`docs/VM_SPEC.md` §15；
  与 ADR-009 的带松弛同族。

## 背景

X76/rej_o/rej_lit 的图内判定是 `_geq_expr(D, _T_DIG_CMP)`，右端是 fp32 标量
权重。真阈值 `_T_DIG = 1+⌈64000(T−1)/3321⌉` 在默认 MAX 下 ≈ 3.2 亿，超过
fp32 精确整数区 2^24=16777216，不可精确表示；烘焙小 MAX（差分测试用 8 →
_T_DIG = 21）则精确。

## 决策

烘焙值取 **≥ 真阈值的最小 fp32 数**（build_vm :2200-2207：struct 单步向上
舍入到下一可表示值）。方向论证：阈值偏高 ⟹ `D ≥ cmp` 的解集是 `D ≥ _T_DIG`
解集的**子集** ⟹ 机器拒 ⊆ 真守卫拒 ⊆ 内核拒。阈值偏低才致命（false
reject 越出内核拒绝集）。默认 MAX 下比较两侧都 ≥ 2^62 量级链长，机器编码
链 ≤8191 位，守卫恒不点火，取整方向不影响任何用例；该规则是防御性不变式。

## 后果

- 小 MAX 精确区（_T_DIG < 2^24）cmp == _T_DIG，差分测试无额外松弛。
- 任何改动该常数的后续工作必须维持"只许偏高"方向，测试里不许为绿灯调低
  阈值。
